# The Extrecated: Prologue (Godot 4)

The playable prologue, from the rainy opening shot to the wreck on the last corner of Kennedy:
- the Kennedy, WA community center as true 3D: foyer, hallway, party room, parking lot, town backdrop
- low-poly, rigid-skinned PS1-style characters with 3D heads, hair and clothing: Kenneth, Adaline, the Stranger, Rachel, Marcus, Denise, background parents, kids and the ACROSS
- a dialogue box with your premade 12-frame portraits, mouth flaps included
- every story beat scripted, including the full ACROSS breach state machine from the debrief
- placeholder synthesized sound

## Running it

1. Install **Godot 4.4** (standard build, not .NET).
2. Choose **Import**, select `project.godot`, then **Run** (F5). The main scene is `scenes/prologue/prologue.tscn`.

The first open takes a little while as models, textures and sounds import. If the first run shows errors about textures, close Godot and open it again; a second import always cleans these up.

| Key | Action |
|---|---|
| W / S or ↑ / ↓ | Forward / back |
| A / D or ← / → | Turn (tank) or move (camera-relative) |
| Shift | Run |
| Q, or back + Shift | Quick turn (180°) |
| **E / Space** | Talk / use / advance dialogue |
| F1 | Switch between tank controls (default) and camera-relative |
| F3 | Debug readout: live camera, control scheme, position |
| F5 (in game) | Restart the prologue |

Gamepad: left stick or D-pad to move, B to run, X to quick turn, A to interact.

**Skip ahead while testing:** under Project → Project Settings → Run, set Main Run Args to `-- start=party`, `-- start=breach` or `-- start=lot`.

## Chapter One (separate scene)

Open `scenes/chapter1/chapter1.tscn` and press **F6** (Run Current Scene). It runs the whole chapter, from the drive home to the turn onto the chapel road and the CHAPTER TWO: THE OLD CHAPEL card.
- C or right mouse aims and F or left mouse fires (in the bathroom).
- Tab opens the items screen, which has ITEMS, KEYS (keys and the codes she has found) and FILES (every note and photo, to reread).
- Skip ahead with `-- start=sprint|inside|barricade|window|bathroom|after|louis|road`.

The beat list, controls and known placeholders are in `docs/CHAPTER1_PLAYTEST.md`.

## What's in it

| Path | Contents |
|---|---|
| `scenes/prologue/prologue.tscn` | The prologue: a 320×240 3D world (SubViewport, scaled 3×), actors, interactables, audio |
| `scenes/environments/community_center.tscn` | The location: geometry, props, lights, cameras, zones, breach and story markers, lot aftermath, town backdrop |

| `dialogue/prologue.json` | All lines, speakers and crowd barks (**draft wording**) |
| `scripts/cutscenes/` | `prologue_director.gd` (the story), `breach_sequence.gd` (the window attack), `drive_sequence.gd` (the BMW) |
| `scripts/dialogue/`, `scripts/ui/hud.gd` | `Dialogue` and `HUD` autoloads: dialogue box, captions, objective, fades, letterbox, impact flash |

| `scripts/player/player.gd` | Movement, animation, footsteps, interaction, stagger |
| `scripts/systems/audio_director.gd` | Ambience presets and one-shot sounds |
| `tools/` | Python generators for the level, characters, textures, sounds and the prologue scene |
| `docs/` | `BLOCKOUT_NOTES.md` (the building), `STORY_PASS_NOTES.md` (models, first story pass), `ENDING_PASS_NOTES.md` (cameras, dialogue, the chase, the ending), `MODEL_PASS_NOTES.md` (3D clothes, heads and hair; the feeding chase) |

## Generated content

**These files are generated by scripts.** Re-running a script overwrites hand edits to its files, so once you start editing a file in Godot or Blender, stop running its generator.

```
python3 tools/build_community_center.py   # level, materials, environments, player.tscn
python3 tools/build_characters.py         # assets/characters/*.glb + atlases
python3 tools/build_prologue.py           # scenes/prologue/prologue.tscn
python3 tools/make_textures.py            # assets/textures/
python3 tools/make_audio.py               # assets/audio/
python3 tools/make_portraits.py           # the crowd portrait sets (--all regenerates every portrait)
```
